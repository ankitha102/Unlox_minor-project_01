# GroupDNA – Hostel Bois Chat Analysis

## 📌 Project Overview

GroupDNA is a Python-based chat analysis project that analyses the WhatsApp group **"Hostel Bois 4ever"**.

The project extracts useful insights from the chat data, such as participant activity, busiest days and hours, word usage, response speed, silent streaks, and personality archetypes.

## 🎯 Objectives

- Parse WhatsApp chat data using Python
- Analyse overall group activity
- Find the most active day and hour
- Create an activity heatmap using NumPy
- Identify frequently used words
- Analyse response speed and silent streaks
- Detect personality archetypes of group members
- Generate a final group analysis report

## 🛠️ Technologies Used

- Python
- NumPy
- Datetime
- File Handling
- Lists, Dictionaries and Sets
- Loops and Functions

## 📊 Features

### 1. Chat Parser
Reads and parses the WhatsApp exported chat file and extracts dates, times, participants, and messages.

### 2. Group Overview
Displays:
- Total messages
- Number of participants
- Chat start date
- Chat end date

### 3. Activity Analysis
Identifies:
- Most active day
- Busiest hour

### 4. Activity Heatmap
Uses NumPy to analyse participant activity across different hours of the day.

### 5. Top Words
Finds the most frequently used words in the group chat and analyses favourite words of participants.

### 6. Response & Silence Analysis
Analyses response times and identifies long silent periods of participants.

### 7. Personality Archetypes
Classifies participants into different chat personalities based on their messaging behaviour.

### 8. Final Report
Generates a complete summary of the GroupDNA analysis.
